The design-agents golden samples text and styles from one emulator-locked frame only after the panel anchor, editor placeholder and status row are present together. The captured full-suite failure showed those latter rows cleared between PTY reads while the panel remained, consistent with a partial paint; the new gate samples a complete frame rather than changing the golden or lengthening a settle timeout.

## Remaining limits

T1 shell activation needs enforceable lifetime ownership of descendants across `setsid()` and reparenting. Process-group kills, PID polls and unsupported kqueue `NOTE_TRACK` cannot prove it. The product refuses the opt-in until that mechanism is available. Direct Seatbelt profile tests still cover filesystem and network confinement only. The progress guard excludes effectful Bash, unknown external task state, oversized or linked worktrees and Git metadata from its unchanged-state claim; it does not add model calls. No paid evaluation or visible terminal drive was run in this round.
