# Independent review, candidates 01–04

Scores are correctness/robustness, security/privacy, design/maintainability, test quality, and scope/usability, each 0–4. I reviewed the anonymous snapshots and submitted tests in order. I did not inspect provenance or other judges. Every candidate built, passed gofmt, vet, staticcheck, targeted race and memory e2e checks, and passed all 29 initial hidden acceptance cases. The broad unit run's `TestHandleSubmit_LeadingPathIsNotACommand` failure also occurs on the unmodified baseline in the same grader environment, so I do not attribute it to these patches. Targeted supplemental and fidelity probes below are independent of submitted tests.

## Candidate 01 — 3 / 3 / 4 / 3 / 4; minor revisions

**Finding (contract, reproduced):** A destination source path that names a FIFO hangs instead of rejecting a nonregular source file. `internal/memory/import.go:276` calls `sourceDigest`, whose existing `internal/memory/sources.go:30-39` opens the path before checking `Mode().IsRegular()`. The supplemental probe timed out after three seconds. A local FIFO under the destination root with a valid imported hash is the trigger. It must be rejected without waiting for a writer. This is a denial of service edge in the new import path, even though the lower level helper predates this patch.

The remaining flow is sound: `internal/cli/memory_import.go:168-201` bounds the read, uses a strict decoder, and checks for trailing JSON; `internal/memory/import.go:68-119` validates all history and rebinds all source records before selecting the highest ID; `:127-191` checks conflicts and writes selected keys in one transaction. The dry-run branch at `:167-184` issues no memory writes. The source path checks at `:246-282` reject lexical and symlink escapes and use the destination file. Successful reports and errors contain no memory text. Existing memory dispatch stays on the old parser except for import (`cmd/kiln/main.go:79`). Documentation in `docs/configuration.md:843-881` explains transfer, policies, and source validation.

Submitted CLI and store tests cover argument errors, round trip, history, source rebinding, stale historical sources, global constraints, conflict policies, and persistent dry-run behavior (`internal/cli/memory_import_test.go`, `internal/memory/import_test.go`). They lack FIFO rejection, cancellation, and a fault-injected database write rollback test. Supplemental probes confirmed dry run does not attempt INSERT and existing `memory --help` still works; fidelity probes confirmed rejection of `[]]`, `[]}`, and trailing JSON values. The hidden grader independently confirmed write rollback, including search/source writes. The one FIFO blocker prevents a ready classification.

## Candidate 02 — 2 / 2 / 2 / 2 / 2; major revisions

**Finding (contract, reproduced):** `internal/cli/personal_memory.go:217` uses `Decoder.More()` after decoding the top-level array. For `[]]` and `[]}`, `More()` returns false, so import succeeds and prints success JSON. The task requires rejection of all trailing content. The fidelity probes reproduced both cases; a separate Go decoder probe confirmed the mechanism.

**Finding (contract, reproduced):** `internal/memory/store.go:457-493` performs UPDATE/INSERT/search/source writes during `--dry-run` and relies on rollback. A destination database trigger that aborts INSERT makes a valid, nonconflicting dry run fail instead of reporting counts without writing. The supplemental probe observed the attempted INSERT. The dry-run contract explicitly says it writes no records or associated entries.

**Finding (contract, reproduced):** Imported source FIFO hangs at `internal/memory/sources.go:101` through the preexisting `sourceDigest` open-before-stat sequence at `:30-39`, as in candidate 01. The supplemental probe timed out.

**Finding (compatibility, reproduced):** `cmd/kiln/main.go:78-79` dispatches *every* memory command before the shared flag parser. Thus existing `kiln memory --help` now exits 2 with usage rather than displaying help; the supplemental probe reproduced this. The dispatch should be limited to import, as the previous command behavior is in scope.

The implementation otherwise validates all history before selection (`internal/cli/personal_memory.go:226-267`), rebinding sources through `internal/memory/sources.go:83-112`, and uses a single transaction for committed changes (`internal/memory/store.go:427-497`). Source boundary, global scope, conflicts, and local lineage are handled correctly in ordinary cases; hidden acceptance passed 29/29. `internal/memory/store.go:454` prints a conflicting key. This is an **uncertain privacy caution**, not scored as an independent violation: keys are identifiers, but a key containing a credential would appear in stderr. Documentation in `docs/configuration.md:844-879` describes the workflow.

Submitted tests cover ordinary policies, a persistent dry-run check, source escape/symlink cases, global history, and some malformed input (`internal/cli/personal_memory_import_test.go`, `internal/memory/import_test.go`). They miss `[]]`/`[]}`, write attempts under dry run, FIFO, and the existing-help regression. The dry-run test inspects final state only, which cannot detect rolled-back writes.

## Candidate 03 — 2 / 3 / 3 / 2 / 3; major revisions

**Finding (contract, reproduced):** `internal/memory/import.go:98-126` issues UPDATE/INSERT/search/source writes for dry runs, then rolls back. A trigger rejecting INSERT makes a valid dry run fail; the supplemental probe confirmed the attempted write. The task requires a dry run to perform validation/conflict analysis without writes.

**Finding (contract, reproduced):** `internal/memory/sources.go:118` calls `sourceDigest`, whose open-before-stat order at `:30-39` hangs on a destination FIFO. The supplemental probe timed out rather than receiving a nonregular-file rejection.

The command parser and decoder (`internal/cli/memory_import.go:52-188`) reject missing/unknown flags and trailing content correctly; fidelity probes passed. The selection loop (`:202-259`) validates historical records and source bindings before choosing the highest ID, including global-history restrictions. A committed batch is transactionally atomic and links replacement to local history (`internal/memory/import.go:75-132`). The import-specific dispatch at `cmd/kiln/main.go:78` preserves old memory help. `internal/memory/import.go:91` includes a key in a conflict diagnostic; a secret-like key is a possible disclosure, but whether an identifier counts as credential text under the contract is uncertain. Documentation in `docs/configuration.md:840-871` is usable.

Submitted tests exercise history collapse, global restrictions, stale historical sources, policy counts, expiry, paths, and persistent dry-run state (`internal/cli/memory_import_test.go`, `internal/memory/import_test.go`). They do not catch dry-run writes, FIFO blocking, cancellation, or fault-injected write rollback. Hidden acceptance passed 29/29; targeted race, vet, and e2e checks passed.

## Candidate 04 — 3 / 3 / 4 / 3 / 4; minor revisions

**Finding (contract, reproduced):** `internal/memory/import.go:139` calls the existing `sourceDigest`, which opens before checking file mode (`internal/memory/sources.go:30-39`). An imported source pointing to a destination FIFO blocks; the supplemental probe timed out. The task requires nonregular source files to be rejected.

Otherwise `internal/memory/import.go:37-67` strictly decodes one array, `:171-226` validates every historical record and source, and `:230-289` analyzes conflicts and applies all selected records in one transaction. Dry runs take the read-only branch at `:256`, and the supplemental trigger probe passed. Rebinding at `:98-149` checks original lexical containment, destination symlinks, hashes, and file limits. The command parser (`internal/cli/personal_memory.go:137-239`) handles import flags and reports; only import bypasses the shared parser (`cmd/kiln/main.go:78-85`). Existing help passed; fidelity probes rejected trailing closing brackets and values. Documentation in `docs/configuration.md:840-879` covers transfer and policy behavior.

Submitted tests are the broadest of these four on record validation and conflicts, including stale active conflicts, unknown source fields, an empty array, and dry-run replacement counts (`internal/memory/import_test.go`, `internal/cli/personal_memory_import_test.go`). `TestImportAtomicOnFailure` at `internal/memory/import_test.go:358-377` uses a validation error that occurs before transaction writes; it does not exercise a mid-transaction database failure. FIFO and cancellation are also untested. The hidden grader supplied write rollback evidence and passed 29/29.

## Comparison and uncertainty

Candidates 01 and 04 have the strongest behavior and clear transaction ownership; both need the shared FIFO source edge fixed before production use. Candidate 04 has slightly broader submitted record tests; candidate 01's tests more directly cover stale historical sources. I assign equal scores because neither covers the blocking edge or injected rollback in its own tests. Candidate 03 is otherwise close but its dry run writes. Candidate 02 additionally accepts trailing malformed input and regresses an existing command. All four passed the broad hidden suite, showing why the targeted probes matter. I would ask a maintainer to confirm whether echoing a conflict key can reveal a credential in actual use; I have not treated it as a decisive contract violation. I did not assess concurrent source-file mutation between validation and commit because no candidate provides a stable snapshot and the task does not state a concurrency model for local file changes.
